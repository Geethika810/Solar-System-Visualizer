# 🌌 Solar System Visualizer

A 2D Solar System Visualizer created using Python and Pygame.

## 📌 Project Description

This project simulates the movement of planets around the Sun.

It uses Pygame for graphics and animation and mathematical functions such as sine and cosine to calculate circular motion.

## ✨ Features

- 🌌 Starry space background
- ☀️ Sun
- 🪐 Eight planets
- 🔄 Planetary orbital animation
- 🟡 Circular orbit paths
- 🌍 Custom Earth design
- 🟤 Jupiter stripes
- 🪐 Saturn rings
- ⚡ Different planetary speeds
